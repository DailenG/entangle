# Entangle website

Static site for https://daileng.github.io/entangle/ (GitHub Pages, `/entangle/` base path; all
asset references are relative so a custom domain needs no changes). No build step, no framework,
no third-party requests: Inter is self-hosted from `assets/fonts/`, Lucide glyphs are inlined in
`index.html`.

Type scale, spacing, radii and icon rules follow the tachyon design system
(DailenG/tachyon, `docs/design/system/`). The palette and the mark are Entangle's own.

## Phase 1: directions

`index.html` currently shows four switchable brand directions. Switching changes the palette
(`html[data-direction]` in `styles.css`), the header mark, the hero copy and the hero animation
(`directions.js`). Desktop: the labelled "Direction" pill in the bottom-right corner. Phones: the
pill under the hero visual, or tap the visual. Keys `1`–`4` switch, `Q` toggles quarter speed.
Query parameters: `?d=<id>&speed=quarter`, plus `&t=<seconds>&picker=open` for captures.

| # | id | Physics | Palette (role: hex) |
|---|----|---------|---------------------|
| 1 | `singlet` | Spin singlet: the same axis measured on both particles always gives opposite results | bg `#F5F1E8`, ink `#1A1A1F`, body `#44454D`, muted `#6B6C75`, A `#C8431F`, B `#176B6B` |
| 2 | `spacelike` | Minkowski diagram: two simultaneous outcomes whose light cones have not met | bg `#0F1115`, ink `#ECEBE6`, body `#B4B6BC`, muted `#868A93`, trace `#F0B23A` |
| 3 | `swap` | Entanglement swapping: a Bell measurement at the repeater entangles A and C, which never met | bg `#1F2B27`, chalk `#EFEBE0`, body `#C7C3B7`, muted `#9A988D`, copper `#D7935B`, slate `#8FB8C9` |
| 4 | `bound` | Bell's inequality: measured correlation E(θ) rising above the local-realist straight line | bg `#F2F5F6`, ink `#0F1B1E`, body `#3C4A4F`, muted `#627179`, trace `#0F7A5A`, bound `#9AA7AC` |

Marks are generated by `scripts/brand/directions.py` into `assets/logo/`; the header draws the
same geometry inline so it recolors with the direction.

Motion respects `prefers-reduced-motion` (a still frame is drawn instead) and pauses when the
canvas is off-screen or the tab is hidden.

## Local preview

```sh
mkdir -p /tmp/srv && ln -sfn "$PWD/site" /tmp/srv/entangle && (cd /tmp/srv && python3 -m http.server 8765)
# open http://localhost:8765/entangle/
```
