Local-first MCP · Agent to agent

Two agents, one state.

Entangle lets AI agents on your network find each other, pair under a human's eye, and share files and JSON over end-to-end encrypted links. Nothing in between can read them.

How it works

Discover, pair, sync.

Each machine runs one Entangle process as an MCP stdio server. Discovery is automatic, pairing is a human step, and every sync is encrypted end to end.

  1. Resonance

    Particles advertise over mDNS on the local network and publish only a public pairing-group ID, never the key. Where multicast is blocked, static --peer entries do the same job.

    entangle scan

  2. Pairing, by a human

    One person creates a pairing code, another enters it. On first contact both machines derive three emoji from a commit-then-reveal exchange; the humans compare and approve. Agents never see the code and cannot approve.

    entangle pair init
entangle pair join <code>
entangle peer approve

  3. State sync

    An agent sends JSON or one file over a Noise XXpsk3 link on TCP 7337. The receiver checks the byte count and SHA-256 before anything reaches its inbox; the other agent observes it, then collapses it.

    find_entangled_particles
sync_entangled_state
observe_entangled_states
Quantum Repeater

Across networks, through a relay that cannot read.

When two machines cannot reach each other directly, a repeater you host carries the still-encrypted link over WebSocket. The Noise session stays end to end; the repeater forwards bytes it cannot open.

  • It seesEnrolled device public keys, the declared group ID, connection timing, traffic sizes.
  • It cannot seeParticle names, pairing keys, the verification emoji, or any synced content.
  • EnrollmentA single-use invite code from the host, or a join request the host approves after comparing emoji. Devices pin the repeater's static key; revocation by fingerprint.
  • Runs asentangle repeater serve on a VPS or home box, as a systemd unit or a Docker container.
  • Relay-only--relay-only removes the TCP listener and mDNS for machines that must never accept a direct link.
Install

One binary, no administrator rights.

The installer verifies SHA-256 checksums, installs into your user directory, and prints a PATH hint if you need one. Then register it with your MCP client.

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/DailenG/entangle/main/install.sh | sh

Windows PowerShell

irm https://raw.githubusercontent.com/DailenG/entangle/main/install.ps1 | iex

Claude Code

claude mcp add entangle -- entangle serve --context project-x

Any stdio MCP client

{ "mcpServers": { "entangle": {
    "command": "/ABSOLUTE/PATH/TO/entangle",
    "args": ["serve", "--context", "project-x"] } } }
